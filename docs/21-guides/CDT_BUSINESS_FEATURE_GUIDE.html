3. Feature catalog

Application map

3.1 Sign-in

Purpose: Secure access with your company account.

How to use: Open the CDT URL → email + password → Sign in. Contact Admin if locked out.

3.2 Cost center filter & search

Purpose: Focus on BrickRed, Agyom, or everything; find people or clients quickly.

How to use: Header Cost Center dropdown + search box. Filters carry into Dashboard and lists.

3.3 Dashboard

Purpose: Portfolio health—headcount, bench, engagement risk, leave today, timesheet gaps, billing.

  1. Open Dashboard.
  2. Optionally set Delivery Owner, Account Owner, Client, Health, Month.
  3. Click KPI cards for underlying detail.

Note: On Leave Today always means today, even if Month is set elsewhere.

3.4 Employees

Purpose: Single source of truth for every person CDT tracks.

CategoryPurposeTypical fields
BillableClient deliveryClient, role, billing, managers
Non-billableInternal orgTeam, support function
BenchAwaiting placementBench start, interviews scheduled/cleared, feedback

Create: Employees → New → category → save → gets CD-#####.

Bench feedback: Open bench employee → review interviews → add Delivery Manager / Account Manager feedback.

Release: Active billable → Release → end date/reason → leaves Active counts; history remains.

3.7 Timesheets

Purpose: Monthly work delivery for billable Active employees.

  1. Timesheets → New → employee + month.
  2. Enter working days / days worked (leave from Approved leave).
  3. Save Pending → Account Owner approves.

One timesheet per employee per month. Approving may create a draft invoice.

3.8 Approvals

Purpose: Account Owner inbox for pending leave and timesheets.

How to use: Approvals → Leave or Timesheet tab → Approve or Reject.

4. Full happy paths by role

4.1 Admin — open the month cleanly

  1. Sign in as Admin.
  2. Settings → Users: confirm Delivery Owner and Account Owner are active.
  3. Clients: cost centers and owners are correct.
  4. Lookups: leave types and release reasons exist.
  5. Optional Import: dry-run → commit.
  6. Spot-check Dashboard and Audit after large imports.
  7. Hand off to Delivery Owner for day-to-day work.

4.2 Delivery Owner — placement to invoice draft

  1. Sign in; set cost center if needed.
  2. Employees → New (Billable) with client and billing.
  3. Bench people as needed; set interviews; add Delivery Manager feedback.
  4. Record Leave when away.
  5. Enter monthly Timesheet as Pending.
  6. After timesheet approval, generate Invoice if not auto-created.
  7. Write monthly Delivery Review.
  8. Use Dashboard for missing TS, at-risk, and bench aging.

4.3 Account Owner — approvals and collections

  1. Sign in → Approvals.
  2. Clear Leave queue (approve or reject with reason).
  3. Clear Timesheet queue when days look right.
  4. Invoices: Pending review → Approved → Sent → Paid.
  5. Reject mismatches with clear reasons.
  6. Dashboard for outstanding/overdue and at-risk clients.
  7. Add Account Manager Feedback on commercial bench cases.

5. What CDT does not do yet

Not in shipped MVP

  • Automatic emails / Slack notifications
  • Live sync from SST
  • Half-day leave or holiday calendars
  • Single Sign-On (SSO)

What is shipped today
